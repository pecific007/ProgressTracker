# Progress Tracker:

This progress tracker is written to track my progress for stuff I am learning/doing.

> [!WARNING]
> It uses my own SQLite3 ORM-style wrapper [plibsqlite](https://github.com/pecific007/plibsqlite).
> Plibsqlite is vulnerable to sql injection.

To run the local server run:
```sh
uv run -m flask run
```
