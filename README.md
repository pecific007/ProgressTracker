# Progress Tracker:

This progress tracker is written to track my progress for stuff I am learning/doing.
> [!CAUTION]
> This project uses my own SQLite3 ORM-style library [plibsqlite](https://github.com/pecific007/plibsqlite).  
> Plibsqlite is vulnerable to sql injection.
---
To run the local flask server run:
```sh
uv run -m flask run
```
